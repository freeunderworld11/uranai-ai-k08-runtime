# CASE_D 固定回帰ケース

対象：西経地域。架空の出生入力としてニューヨークの固定座標（北緯40.7128、東経-74.006）、2000-01-01 12:00:00、America/New_York、標準時-05:00、UTC 17:00:00を使用します。JD UTは2451545.2083333335です。西経とUTC offsetの両方を負の値のまま保持します。経度から時差を推定せず、K02の時刻・地域の固定TZDB検査を通します。

入力と期待値はtest/fixtures/case-d.json、参照出力はcase-d-native.txt、生成処理はscripts/prepare-case-d.pyです。公式swetest64 2.10.03を別プロセスで実行し、配布データ0.2.2から10天体黄経・速度、ASC/MC、12カスプを取得しました。実行引数と実行ファイルSHA-256を記録し、端末固有パスのみ公開用に置換しています。45組のアスペクト成立種類・不成立はnative黄経から別のPython処理で算出しました。Worker実装や応答を期待値生成に使わず、通常のテストで期待値を再生成しません。

K02固定入力をAPIに渡し、入力保持、JD、10天体とフラグ258、Placidus正常状態、ASC/MC、12カスプ、45組の成立状態を確認します。黄経許容差0.01度、ASC/MC・カスプ0.05度、速度0.000001度/日。速度は印字精度を考慮した開発用条件で、K19正本の規定値ではありません。アスペクトの成立種類・不成立は完全一致を要求します。強度等の詳細は既存の個別テストが担当します。

ローカルWorkers互換環境で全76テストが成功しました。CASE_A〜Dが固定参照値とのローカル照合済みです。K02のPASS等はテスト用申告であり実運用承認ではありません。nativeとWASMは同系統の天文エンジン・同じデータとの比較であり、独立天文モデルの認証ではありません。K19全体の受入、本番Cloudflare環境、ライセンス等の承認は未完了です。K09_USAGE_STATUSはLOCAL_BLOCKを維持します。
