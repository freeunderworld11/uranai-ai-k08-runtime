# CASE_B 固定回帰ケース

対象：北半球・夏時間あり。架空の出生入力としてロンドンの固定座標（北緯51.5074、東経-0.1278）、2000-07-01 12:00:00、Europe/London、夏時間+01:00、UTC 11:00:00を使用します。JD UTは2451726.9583333335です。固定TZDB 2026cでこの現地時刻とUTCの一致を検査します。DST_STATUSのDSTはfixtureの申告ラベルであり、ラベルだけを根拠に夏時間を認証しません。

入力・期待値はtest/fixtures/case-b.json、参照出力はcase-b-native.txt、再生成用の独立処理はscripts/prepare-case-b.pyです。公式swetest64 2.10.03の別プロセスで同じSwiss Ephemerisデータ0.2.2を使い、10天体黄経・速度、ASC/MC、12カスプを取得しました。実行引数と実行ファイルSHA-256を記録しています。端末固有パスは公開用に置換しました。

主要アスペクト45組の成立種類・不成立はnative出力の黄経からPythonで計算し、Workerの計算処理を期待値生成に使用していません。通常テストで期待値を再生成しません。黄経0.01度、ASC/MC・カスプ0.05度、速度0.000001度/日の許容差を適用します。速度の値は印字精度を考慮した開発用条件であり、K19正本の規定ではありません。成立種類・不成立は完全一致を要求します。

CASE_Aと同じAPI照合処理でK02入力保持、JD、10天体、フラグ258、Placidus正常状態、ASC/MC、12カスプ、45組の成立状態を確認します。追加の異常系では、現地時刻から冬時間+00:00を用いてUTCを12時とした入力を拒否することを確認します。算術的には一致しても地域の実際の時刻規則と異なるため計算を開始しません。

ローカルWorkers互換環境で全74テスト成功。CASE_AとCASE_Bの固定ケースはローカル照合済みです。K02_AUDIT_STATUS=PASSはテスト用の入力であり、実運用K02の承認ではありません。nativeとWASMは同じ天文エンジン系列・データを使用しており、独立モデル認証ではありません。K19全体の監査・本番環境受入は未完了、K09_USAGE_STATUSはLOCAL_BLOCKを維持します。
