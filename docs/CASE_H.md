# CASE_H 水星逆行（2026-09-11）

東京固定座標（北緯35.6762、東経139.6503）、2000-03-01 21:00:00（Asia/Tokyo、+09:00、UTC 12:00:00）の架空入力を使用します。公式swetest64の水星黄経は341.4803902度、黄経速度は-1.0413769度/日。逆行期間内の固定時点であり、stationの瞬間の検証はCASE_Iで別途扱います。

入力・期待値はtest/fixtures/case-h.json、参照出力はcase-h-native.txt、生成処理はscripts/prepare-case-h.pyです。公式swetest64 2.10.03と配布データ0.2.2の別プロセスから10天体黄経・速度、ASC/MC、12カスプを取得しました。引数・実行ファイルSHA-256を保存し、端末固有パスのみ置換。45組のアスペクト成立種類・不成立はnative黄経からPythonで算出し、Worker実装や応答を期待値生成に使いません。通常テストで期待値を再生成しません。

共通許容差は黄経0.01度、ASC/MC・カスプ0.05度、速度0.000001度/日、JD差1e-9日未満です。速度とJDは開発用の印字精度を考慮した条件です。アスペクト成立種類・不成立は完全一致。さらに水星速度が負、motionと正式結果MOTIONがRETROGRADEであることを確認します。station感度は未認証のnullを保持し、逆行だけを理由にstationと判定しません。

ローカルWorkers互換環境で全84テスト成功。nativeとWASMは同系統のSwiss Ephemeris・同じデータとの回帰比較であり独立モデル認証ではありません。K02状態はテスト用申告です。本番承認・K19全体の受入は保留し、K09_USAGE_STATUSはLOCAL_BLOCKを維持します。
