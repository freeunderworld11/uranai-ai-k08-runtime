# CASE_A 固定回帰ケース

対象：通常北半球・DSTなし。テスト用の架空の出生入力です。東京の固定座標（北緯35.6762、東経139.6503）、2000-01-01 21:00:00、日本標準時+09:00、UTC 12:00:00、JD UT 2451545を使用します。K02申告値はテストfixtureであり、実運用のK02監査合格証明ではありません。

入力・期待値・許容差は `test/fixtures/case-a.json`、native参照出力は `test/fixtures/case-a-native.txt`。Swiss Ephemeris公式swetest64 2.10.03を別プロセスで実行し、同じ配布データ0.2.2を使用しました。実行ファイルのSHA-256はfixtureに記録しています。実行引数はrawの先頭行に記録し、端末固有パスだけを置換しています。

10天体の黄経と黄経速度、ASC・MC、12カスプを固定しています。主要アスペクトはnativeの黄経から独立したPython処理で45組の成立種類・不成立を算出しました。生成処理は `scripts/prepare-case-a.py`。Workerの計算コードやAPI出力を期待値の生成に使用していません。通常テストで期待値を再生成しません。

黄経許容差0.01度、ASC/MC・カスプ0.05度はK08の規定。速度は印字の丸め幅より大きい0.000001度/日を開発用許容差として明示的に追加しています。これはK19正本に指定された速度許容差ではありません。45組のアスペクト成立状態・種類は完全一致を要求します。アスペクトの強度・exactness_ratio等の個別検査は既存のアスペクトテストが担当し、このfixtureの完全一致対象には含みません。

Workers互換ローカル環境で `/calculate/k02` を実行し、K02入力が変更されないこと、JD、全参照値、SWIEPH/SPEED返却フラグ、Placidus正常状態を検査します。数値の比較と本番承認を分離し、CASE_Aが成功してもREGRESSION_SUITE_VALIDはnull、K09_USAGE_STATUSはLOCAL_BLOCKです。

nativeとWASMは同系統のSwiss Ephemerisと同じデータを使用しています。これは別実行経路との回帰一致であり、独立した天文モデルや絶対UTC精度の認証ではありません。本番Cloudflare実環境、CASE_B〜L、ライセンス・配布物の承認等は引き続き未完了です。
