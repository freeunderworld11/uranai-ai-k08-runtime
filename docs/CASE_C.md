# CASE_C 固定回帰ケース

対象：南半球。架空の出生入力としてシドニーの固定座標（北緯-33.8688、東経151.2093）、2000-07-01 12:00:00、Australia/Sydney、標準時+10:00、UTC 02:00:00を使用します。JD UTは2451726.5833333335。南緯を負の値として保持し、北緯への置換やハウスの反転補正を行わず照合します。

入力と期待値はtest/fixtures/case-c.json、参照出力はcase-c-native.txt、生成処理はscripts/prepare-case-c.pyです。公式swetest64 2.10.03を別プロセスで実行し、同じ配布データ0.2.2から10天体黄経・速度、ASC/MC、12カスプを取得しました。実行ファイルSHA-256と引数を記録し、端末固有パスは置換しています。45組のアスペクト成立種類・不成立はnative黄経から別のPython処理で算出し、Workerの計算コードを期待値生成に使っていません。通常テストは固定期待値を再生成しません。

K02固定入力をAPIに渡し、入力保持、JD、10天体と返却フラグ258、Placidus正常状態、ASC/MC、12カスプ、45組の成立状態を検証します。黄経許容差0.01度、ASC/MC・カスプ0.05度、速度0.000001度/日。速度の条件は印字精度を考慮した開発用条件で、K19正本の数値指定ではありません。アスペクトの成立種類・不成立は完全一致を要求します。強度等の詳細は既存の個別テストが担当します。

追加後のローカルWorkers互換環境の全75テストが成功しました。CASE_A〜Cは固定参照値とのローカル照合済みです。K02のPASS等の状態はテスト用申告であり実運用承認ではありません。同系統のSwiss Ephemeris・同じデータとの回帰一致であって独立天文モデルの認証ではありません。南半球全地点・全年代の保証、本番Cloudflare環境の受入、K19総合監査は未完了です。K09_USAGE_STATUSはLOCAL_BLOCKを維持しています。
